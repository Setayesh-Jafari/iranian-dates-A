# FARVAND — کاتالوگ صادراتی خرمای ایرانی
### Premium Iranian Dates · B2B Export Catalog — 12 pages, layered & editable

این پوشه شامل **خروجی نهایی کاتالوگ صادراتی FARVAND** در چهار قالب است:
فایل‌های **PSD لایه‌باز** (مهم‌ترین خروجی)، PDF چاپی، PowerPoint قابل‌ویرایش، و پیش‌نمایش صفحات.

| پوشه | فرمت | توضیح |

| `psd/` | **PSD (Photoshop)** | ۱۲ فایل، هر صفحه یک PSD جداگانه — A4 عمودی، ۳۰۰dpi — **تمام متن‌ها لایهٔ تایپ زنده** |

## ✏️ روش ویرایش در فتوشاپ / How to edit the PSDs

1. فونت‌های **Playfair Display** و **Inter** را نصب کنید (رایگان).
2. فایل PSD را باز کنید — هر گروه لایه با شماره و نام فارسی‌خوان مشخص است:
   `01 · BACKGROUND` / `02 · PHOTOGRAPHY` / `03 · OVERLAYS` / `04 · FURNITURE` / `05 · CONTENT`
3. **تمام نوشته‌ها لایهٔ متن زندهٔ Type Tool هستند** — روی لایه‌های `TXT · …` دابل‌کلیک کنید و تایپ کنید.
4. **عکس‌ها** لایه‌های جدا داخل گروه Photography هستند — با Place & Replace عوض کنید.
5. فیلدهای `[بین براکت]` را با اطلاعات واقعی شرکت جایگزین کنید (فهرست کامل پایین ⬇️).
6. بعد از ویرایش: `File → Export → Save as PDF` یا `Print → Save as PDF` با اندازهٔ A4.

> 💡 نکته مهم: کاتالوگ طوری طراحی شده که **هیچ ادعای تأییدنشده‌ای وارد آن نشود**. هر عدد یا اطلاعاتی که هنوز ندارید، عمداً به‌صورت `[PLACEHOLDER]` باقی مانده است. لایه‌های `TXT · Table · … status` کنار هر سطر وضعیت را نشان می‌دهند (Confirmed / To be supplied).

## 🤖 پرامپت اصلاح‌شده برای Claude

فایل [`prompts/CLAUDE_PROMPT.md`](prompts/CLAUDE_PROMPT.md) یک بریف کامل و حرفه‌ای است که جایگزین پرامپت قبلی می‌شود:

- سیستم برند دقیق (همان چهار رنگ + تایپوگرافی)
- ساختار ۱۲ صفحه‌ای با جزئیات (همهٔ ارقام + داستان ما)
- قوانین گرید، سلسله‌مراتب و عکاسی
- **قواعد سخت صحت اطلاعات** — هیچ عدد یا گواهی‌نامه‌ای ساخته نمی‌شود
- معماری لایه‌ها در PSD (نام‌گذاری لایه‌ها، متن زنده)
- چک‌لیست تحویل و معیارهای کنترل کیفیت

**نحوه استفاده:** کل محتوای بین «---» را در Claude بچسبانید (Artifacts روشن)، و اگر تصویر کاور مرجع دارید همراه پرامپت آپلود کنید.

## 🔄 بازتولید خروجی‌ها (اختیاری)

اگر تغییرات انبوه خواستید (مثلاً تغییر رنگ یا متن در همهٔ صفحات):

```bash
cd generator
npm install          # نیاز به Node.js 18+
node build.js        # تولید PSD + PDF + PPTX + پیش‌نمایش در out/
```

ساختار صفحات در `generator/pages.js` و رنگ/فونت در `generator/theme.js` تعریف شده است.
